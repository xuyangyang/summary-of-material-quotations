# 采购订单材料分析系统

本地/局域网版：上传采购订单 Excel 后，自动解析“材料 / 规格”，归并同种材料，提供历史价格、厂家比价、搜索与导出。

## 功能

- 数据导入：上传 `.xlsx`，显示批次与有效 / 未归类行数。
- 材料归类：同种材料归组，展开查看原始采购记录。
- 搜索：按项目、供应商、采购日期、材料分类、材料名称筛选；材料名称支持精确、模糊、AI 语义匹配。
- 历史价格：折线图和价格明细，显示最低、最高、简单均价、加权均价、最近价。
- 厂家比价：同种材料下各厂家价格对比。
- 导出中心：导出材料归类、历史价格、厂家价格 Excel。

## 安装与启动

前置条件：

- 已安装 Python 3.10 或更高版本，并加入 PATH。
- 已安装 Node.js，并加入 PATH。

首次运行：

1. 双击 `install.bat`，自动安装后端 Python 依赖和前端 npm 依赖。
2. 双击 `start.bat`，自动启动后端和前端，并打开浏览器。

以后日常使用只需双击 `start.bat`。

如未自动打开，可手动访问：

- 本机前端：`http://127.0.0.1:5173`
- 后端：`http://127.0.0.1:8000`
- 局域网前端：`http://本机局域网IP:5173`

说明：局域网访问还需在 Windows 防火墙放行 TCP 8000 和 5173。

## 后端测试

```bash
cd backend
pytest -v
```

测试会使用独立的临时 SQLite 数据库，不会污染本地数据。

## 数据与配置

- 数据库：`backend/data/app.db`（SQLite）。
- DeepSeek 配置：`backend/.env`，其中 API Key 仅保存在本地，不会进入版本控制。
- 材料名称 AI 匹配依赖 DeepSeek；DeepSeek 不可用时自动降级为模糊匹配。
